# 思维地图・看见地理

一个可直接打开的静态网站原型，已预置“思维地图典例”文件夹中的 15 张作品。

## 使用

直接用浏览器打开 `index.html` 即可体验。若浏览器限制本地文件存储，可在此文件夹启动一个静态文件服务器后访问；网站不需要安装依赖。

## 已实现

- 发现页、关键词搜索、按学段与主题筛选。
- 首页和资源库均支持在单行组合检索：关键词、主题/地理类别、学段、地图类型、来源、绘图形式；资源库还可按视觉特性和标题排序。
- 资源详情、图片/PDF/视频预览、下载、分享链接和收藏。
- 地图来源标签（原创、书籍、期刊文献）和绘图形式标签（手绘、AI生成、GIS制图、SketchUp 等）；上传时填写，并显示在资源卡片和详情页中。预置典例标签按用户提供的分类表更新。
- 资源详情评论区：支持昵称、评论发布和评论点赞，记录保存在当前浏览器。
- 洪涝灾害动态演示：直接以原始“洪涝灾害的成因”平面思维地图为底图，叠加降雨、坡面汇流、河流水位上涨和低洼地漫溢效果；可调节降雨强度、地表下渗能力与湖库调蓄。
- 发布地图：填写标题、作者、主题、学段、适用范围、空间思维目标与教学建议；选择图片、PDF、视频或 GIS 文件。
- 账号与审核演示：右上角分别提供登录和注册；注册中可选一般用户或管理员。一般用户提交资源后状态为“待审核”；管理员上传直接发布，并可在“审核管理”中通过或驳回一般用户提交。
- 分类体系：自然地理（天文、地球运动、地质、地貌、气候、水、植被、土壤、综合）和人文地理（人口、城市、农业、工业、第三产业、交通、综合），资源库可按大类和类别筛选。
- 发现页主搜索栏可组合关键词、学段、主题大类/类别和地图类型筛选；主题菜单按自然地理、人文地理分组。首页不再显示“按主题探索”区块。
- 资源库页面提供“搜索资源”按钮，移除了可见的“全部主题”筛选栏。
- 发布的文件和信息使用浏览器 IndexedDB 保存；账号、登录状态和收藏使用浏览器本地存储。数据仅存在当前浏览器/设备，不会自动同步给其他人。
- 评论内容和点赞状态也保存在本地浏览器，不会自动同步给其他访问者。
- GIS 工作台：世界地形、中国地形、中国行政区示意底图，可切换地形、河流、道路、边界和聚落图层。

## GIS 说明

GIS 工作台内置的是平台生成的教学示意图，便于演示图层开关和空间关系观察，不是测绘级底图或真实行政边界数据。用户上传的 GeoJSON、KML、SHP 等文件可保存和下载；当前版本不会把它们解析成地图图层。若要给多人共同上传、共享资源，或显示真实在线 GIS 服务，需要部署后端、数据库、对象存储，并配置正式地图服务。

洪涝过程演示是在原图上进行的定性教学动画；水位读数用于观察条件变化，不是基于真实降雨、地形或水文数据的预报结果。

## 账号与多人部署

当前账号和管理员审核流程用于本地原型演示。账号、管理员身份和审核状态都只在该浏览器有效，静态网站无法在其他设备上验证管理员权限或共享审核队列。正式多人使用前，需要把账号认证、角色权限、资源数据库和文件存储迁移到受控后端；不要把本地演示版作为安全的生产权限系统。
